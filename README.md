# 🎬 Netflix Data Analysis Dashboard

An interactive **Netflix Data Analysis Dashboard** developed using **Microsoft Power BI** to analyze Netflix movies and TV shows and identify useful trends, patterns, and insights from the dataset.

![Netflix Dashboard](netflix-dashboard.png)

---

## 📌 Project Overview

This project focuses on analyzing Netflix's content library using Power BI.

The dashboard provides an interactive view of Netflix content based on factors such as:

- Movies vs TV Shows
- Release Year
- Content Rating
- Genre
- Country
- Duration
- Year Added
- Content Type

The goal of this project is to transform raw Netflix data into meaningful visual insights using data cleaning, data transformation, data visualization, and interactive reporting.

---

## 🎯 Project Objectives

- Analyze the distribution of Movies and TV Shows on Netflix
- Identify content trends over the years
- Analyze popular genres
- Understand content distribution by country
- Analyze ratings and content categories
- Identify changes in Netflix's content library over time
- Build an interactive and user-friendly Power BI dashboard

## 🔄 Data Preparation

The dataset was prepared before visualization using Power Query.

The data preparation process included:

1. Removing unnecessary columns
2. Handling missing values
3. Cleaning text fields
4. Transforming columns
5. Splitting and formatting data where required
6. Preparing the dataset for analysis
7. Creating relationships/calculations required for reporting
